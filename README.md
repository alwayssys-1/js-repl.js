# Js-repl js Consola

*Corres:*
`node js-repl.js`

*Se ve así:*
JavaScript REPL - escribe como en Python

```
>>> 1+1
2
>>> let x = 5
>>> x*2
10
>>> ["hola", "mundo"].join(" ")
hola mundo
>>> function recuadro(t){return `┌─${'─'.repeat(t.length)}─┐\n│ ${t} │\n└─${'─'.repeat(t.length)}─┘`}
>>> recuadro("hola")
┌──────┐
│ hola │
└──────┘
>>> .exit
Bye!
```
